## System Overview

This repository implements a multi-rate simulation of a single-axis PAT system
including gimbal dynamics, structural modes, disturbances, sensors, estimation,
and feedback control.

## Deliverables

Graphs under `outputs/` are generated by the scripts in `scripts/<part>/`. 
The scripts print their numbers to the console and generate plots.

Run a whole part with one command:

```
python scripts/run_part1.py
python scripts/run_part2.py    # ~ 5 mins runtime
python scripts/run_part3.py    # ~10 mins runtime
```

Each runner executes that part's scripts in order, times them and prints a
summary. A failure in one script does not stop the rest.

The individual scripts below are standalone and can also be run on their own,
in any order.

**Part 1** - plant, sensor and fundamental-limit characterisation.

```
python scripts/part1/characterize_plant.py          # bode.png, pole_zero.png
python scripts/part1/characterize_camera.py         # platform_psd.png, camera_alias.png
python scripts/part1/analyze_fundamental_limits.py  # sensitivity.png
```

**Part 2** - camera-only loop. One controller: a two-stage lead compensator with
a rolloff pole (`src/pat_sim/control/lead_lag_design.py`).

```
python scripts/part2/design_lead_lag.py       # design point + loop_bode.png
python scripts/part2/analyze_sensitivity.py   # sensitivity.png
python scripts/part2/analyze_tonals.py        # tonal_drift.png, tonal_aliasing.png
python scripts/part2/evaluate_closed_loop.py  # psd_before_after.png, time_domain.png,
                                              # saturation.png
```

**Part 3** - the same compensator, driven by a fused gyro + camera estimate
instead of the raw camera (`src/pat_sim/control/fused_design.py`,
`src/pat_sim/estimation/estimator.py`).

```
python scripts/part3/characterize_timing.py   # timing_budget.png
python scripts/part3/evaluate_sensors.py      # sensor_visibility.png
python scripts/part3/evaluate_fusion.py       # fusion_tracking.png
python scripts/part3/design_fused_loop.py     # fused_loop_bode.png, crossover_sweep.png
python scripts/part3/evaluate_closed_loop.py  # psd_before_after.png, time_domain.png
```
